# 智能考务系统使用说明书

## 1. 软件用途与能做什么

- 管理考试科目与考试时间
- 依据教师信息自动编排监考安排，并导出 Excel
- 根据考生名册与考场设置生成考场/座位编排，并导出 Excel
- 批量生成打印资料：台角纸、桌角纸、准考证、考生信息表（班级/考场），支持 Excel/PDF

## 2. 安装与启动

### 2.1 推荐方式：直接运行 EXE

1. 双击运行：`智能考务系统.exe`

### 2.2 首次启动：授权/证书校验

首次启动可能会弹出“证书校验”窗口：

1. 点击“复制机器码”，把机器码发给开发者获取注册码
2. 将获得的注册码粘贴到输入框
3. 点击“验证注册码”
4. 验证通过后会自动进入主窗口；下次启动通常会直接进入主窗口

## 3. 主界面与推荐流程

主窗口顶部有 5 个功能入口：

- 科目设置
- 监考编排
- 考场编排
- 资料打印
- 使用说明

推荐流程（第一次使用请严格按顺序）：

1. 科目设置：准备“考试科目与时间”
2. 监考编排：导入教师信息并生成监考安排
3. 考场编排：导入考场设置与考生名册并生成座位编排
4. 资料打印：基于考场编排结果批量生成台角纸/桌角纸/准考证/信息表

## 4. 科目设置（第 1 步）

适用：维护本次考试的科目名称、考试日期、考试时间。

常用操作：

1. 设置“考试科目数”
2. 逐科目填写并点击“添加/更新科目”保存
3. 可用“导入科目信息”从 Excel 一次性导入
4. 用“导出科目信息”保存备份（默认文件名 `科目信息.xlsx`）

科目信息模板（通过“生成模板文件”获取）：

- 必填列：科目名称、考试日期、考试时间
- 可选列：考试时长（分钟）、备注

重要规则（请务必注意）：

- 同一考试日期不允许时间冲突：如果两个科目在同一天，且时间段有交集（重叠），系统会提示“考试时间冲突”，不允许保存/导入。时间段首尾相接不算冲突，例如 `08:30-10:00` 与 `10:00-11:30` 允许。
- 考试时长可以不填：模板中的“考试时长（分钟）”为选填。留空时，系统会按“考试时间”的起止时间自动计算分钟数（例如 `08:30-10:30` 自动计算为 120 分钟）。

## 5. 监考编排（第 2 步）

适用：导入教师信息，设置监考模式与约束条件，生成监考安排并导出。

### 5.1 推荐操作顺序

1. 先确认“科目设置”已完成（监考编排需要知道科目数量；时长均衡还需要每科的考试时长）。
2. 设置“考场数”“监考模式（单/双）”“均衡模式（场次/时长）”。
3. 点击“生成模板文件”，得到 `教师信息模板.xlsx`，按模板填写后点击“导入教师信息”。
4. 若为“双监考”，可按需勾选：
   - 男女搭配（同一考场两位监考性别不同）
   - 本外校搭配（同一考场两位监考来源不同）
5. 点击“安排监考”生成结果。
6. 若结果有少量不满意：用“手动调整”在“监考总览表”中交换两个单元格的监考老师。
7. 点击“导出安排结果”（默认文件名 `监考安排.xlsx`）。

### 5.2 教师信息模板字段（重点解释）

模板中列名以软件生成的为准。下面是对关键字段的“怎么填、有什么影响”的说明：

- 姓名（必填）：不能为空；姓名重复会导致导入失败。
- 最大监考段数（强烈建议填写）：表示该教师本次最多监考多少个“科目场次”（上限不应超过科目数）。填得越小，越容易出现“部分考场无人/不完整”。留空时，系统会按“科目数”作为默认上限。
- 不监考科目（可选，但很重要）：用于禁止该老师监考指定科目。
  - 支持填写“科目编号”或“科目名称”，多个用逗号/分号/顿号/空格分隔均可。
  - 示例：`语文, 数学` 或 `1,3,5` 或 `科目2;科目4`。
  - 如果填写了无法识别的科目（名称不匹配、编号越界等），会导入失败。
- 历次监考时长（分钟）（可选）：用于“时长均衡”模式。
  - 填写整数分钟（>=0），留空视为 0。
  - 建议把老师以往考试监考累计分钟数填进去，这样系统会尽量让“历次 + 本次”的总分钟数更均衡。
- 预设监考考场（可选）：用于“指定某位老师尽量/必须在某个考场监考”。
  - 填写 1..考场数 的整数（代表第几个考场/试室）。
  - 若越界或不是数字，系统会提示警告并忽略该预设（不影响导入）。
  - 一旦填写且有效：系统在自动安排与补全时会把该老师仅安排在指定考场；手动调整/优化时也会尽量避免把该老师换到非预设考场。
- 性别、是否本校（双监考且启用搭配时必填）：当你勾选“男女搭配/本外校搭配”时，需要这些字段来做约束判断；缺失会导致导入失败或无法生成。

### 5.3 均衡模式怎么选（场次均衡 / 时长均衡）

- 场次均衡：优先让每位老师的监考“次数”尽量接近，适合所有科目时长差不多、或你不想维护“历次监考时长”的情况。
- 时长均衡：按“监考总分钟数”尽量均衡，适合科目时长差异较大、或需要把“历次监考时长”也纳入公平性考虑的情况。
  - 前置建议：先在“科目设置”把每科考试时间填准确；考试时长可不填（系统会用时间段自动算分钟数）。
  - 如果系统无法获取某些科目时长，个别流程会使用默认值（例如 120 分钟）参与计算，因此科目时间越准确，时长均衡越可靠。

### 5.4 预设监考安排 / 导入监考安排（适合“部分考场指定人选”）

当你希望“某些科目某些考场必须是指定老师”，可以用两种方式：

1. 预设监考安排（推荐做法）
   - 点击“预设监考安排”
   - 先“生成空监考表”（默认文件名 `预设监考模板.xlsx`），按你需要在表格里填入老师姓名（单监考填一个，双监考填监考员1/2）
   - 再用“导入预设安排”导入
   - 说明：预设导入的单元格会被系统标记为“锁定”，后续自动安排/补全会在剩余空位上继续排布，且不会改动这些预设位置
2. 导入监考安排
   - 用于导入一份你已经做好的“监考总览表”Excel
   - 导入时会校验：老师是否存在、是否能监考该科、是否超出最大监考段数；双监考还会校验搭配约束

### 5.5 手动调整（小范围微调）

- 点击“手动调整”进入调整模式
- 到“监考总览表”里依次点击两个要交换的姓名，系统会尝试交换并自动校验约束
- 若提示交换失败：通常是因为触发了“不监考科目”“最大监考段数”“男女/本外校搭配”“预设监考考场”等限制

## 6. 考场编排（第 3 步）

适用：把“考生名册”分配到“考场与座位号”，并导出编排结果。

推荐操作顺序：

1. 点击“生成模板文件”，按需生成并填写：
   - `考场设置模板.xlsx`
   - `考生名册模板（顺序编排、随机编排）.xlsx` 或 `考生名册模板（3+1+2选科编排）.xlsx`
2. 先“导入考场设置”，再“导入考生名册”
3. 选择编排模式：
   - 顺序编排：按名册顺序分配
   - 随机编排：随机打散后分配
   - 3+1+2 选科编排：按选科组合分散安排
4. 点击“开始考场编排”
5. 编排完成后点击“导出考场编排”（默认文件名 `考场编排结果.xlsx`）

考场设置模板（通过“生成模板文件”获取）：

- 必填列：序号、考场号、考场人数
- 可选列：考场（未填会自动生成）

考生名册模板（通过“生成模板文件”获取）：

- 顺序/随机：班级、学号、考号、姓名
- 3+1+2：班级、学号、考号、姓名、选科

## 7. 资料打印（第 4 步）

资料打印页包含 4 个子页签：

- 台角纸生成
- 桌角纸生成
- 准考证生成
- 考生信息表生成

### 7.1 通用使用步骤（四个子页签都适用）

1. 选择“数据来源”（三选一）：
   - 生成空白模板：只生成空表（用于后续手工填写或空表打印）
   - 导入考生数据：从 Excel 导入（通常会弹出“列映射”窗口，把 Excel 表头映射到系统字段）
   - 从考场编排导入：直接读取“考场编排”页当前编排结果（推荐优先使用）
2. 选择“保存路径”（默认会带出建议文件名）
3. 勾选输出格式：
   - Excel（可编辑）
   - PDF（推荐打印更稳定）
4. 点击“开始生成”，等待进度条完成；完成后可选择打开文件夹

当你选择“导入考生数据”时，通常需要在“列映射”窗口能映射到以下字段：

- 考场、考场号、座位号、考生姓名、考生考号、班级、学号

### 7.2 台角纸生成

适用：按考场/座位批量生成台角纸。

推荐做法：

- 先在“考场编排”完成编排 → 再在“台角纸生成”选择“从考场编排导入” → 输出 PDF

默认文件名：`台角纸_批量生成`


### 7.3 桌角纸生成

适用：桌角纸与座位布局打印。

要点：

- 先在“座位布局设置”里设置布局（行列、排布方式等）
- 数据来源推荐“从考场编排导入”
- 预览区可在“座位布局 / 桌角纸”两个标签间切换查看效果

默认文件名：`桌角纸_批量生成`

### 7.4 准考证生成

适用：批量生成准考证（含科目与考试时间）。

要点：

- 点击“设置考试科目”配置科目与时间（建议先在“科目设置”里维护好，再在此处核对）
- 数据来源推荐“从考场编排导入”
- 输出格式推荐 PDF

默认文件名：`准考证_批量生成`

### 7.5 考生信息表生成（班级 / 考场）

适用：生成可打印的考生信息汇总表，支持按“班级”或按“考场”两种组织方式。

使用方法：

1. 在右侧“模板预览”中选择：
   - 班级：生成“考生信息表（班级）”
   - 考场：生成“考生信息表（考场）”
2. 默认标题与默认文件名会随页签变化：
   - 班级：文件名默认 `考生信息表（班级）_批量生成`
   - 考场：文件名默认 `考生信息表（考场）_批量生成`

## 8. 模板与必填列（汇总表）

建议优先使用软件内“生成模板文件”，再把你的数据复制进模板中导入，成功率最高。

| 场景 | 模板文件名（默认） | 必填列（至少需要这些表头） |
|---|---|---|
| 科目设置导入 | 科目信息模板.xlsx | 科目名称、考试日期、考试时间 |
| 监考编排导入 | 教师信息模板.xlsx | 姓名 |
| 考场编排导入（考场设置） | 考场设置模板.xlsx | 序号、考场号、考场人数 |
| 考场编排导入（考生名册：顺序/随机） | 考生名册模板（顺序编排、随机编排）.xlsx | 班级、学号、考号、姓名 |
| 考场编排导入（考生名册：3+1+2） | 考生名册模板（3+1+2选科编排）.xlsx | 班级、学号、考号、姓名、选科 |
| 打印页导入（列映射） | 你自己的 Excel | 考场、考场号、座位号、考生姓名、考生考号、班级、学号 |

## 9. 输出文件说明（常用默认名）

- 科目导出：`科目信息.xlsx`
- 监考导出：`监考安排.xlsx`
- 考场编排导出：`考场编排结果.xlsx`
- 资料打印（默认名，扩展名由你选择 Excel/PDF 决定）：
  - `台角纸_批量生成`
  - `桌角纸_批量生成`
  - `准考证_批量生成`
  - `考生信息表（班级）_批量生成` / `考生信息表（考场）_批量生成`

## 10. 常见问题（快速排查）

### 10.1 监考安排不完整 / 部分考场没人

优先检查：

- 教师人数是否不足（双监考需要更多教师）
- “最大监考段数”是否过小
- “不监考科目”限制是否过多
- 双监考下是否同时启用了过多约束（男女搭配/本外校搭配）

建议操作：

- 放宽约束、增加教师、提高最大监考段数后重新“安排监考”
- 用“手动调整”做小范围微调

### 10.2 导入失败（提示缺列或格式不正确）

建议操作：

- 先用“生成模板文件”拿到标准模板，再把你的数据复制进去导入
- 确认 Excel 表头没有合并单元格、没有前后空格
- 日期/时间按模板示例格式填写
- 若提示“无法导入文件”：检查是否确实使用了软件生成的模板文件（或模板列名完全一致），以及填入的数据是否符合模板里的填写规范（例如：最大监考段数为正整数；历次监考时长为>=0整数；不监考科目能被识别）。

### 10.3 资料打印导入时不知道怎么映射列

建议操作：

- 优先选择“从考场编排导入”，无需映射
- 如必须导入：确保 Excel 表头包含“考场/考场号/座位号/姓名/考号/班级/学号”等对应信息，再在映射窗口逐项选择

### 10.4 打印效果异常（排版错位/缺字）

建议操作：

- 优先导出 PDF 再打印（比直接打印 Excel 更稳定）
- 打印时选择“适合页面/缩放”需谨慎：若出现错位，改为“实际大小”或关闭缩放再试
- 若 PDF 缺字，优先换一台电脑或更换 PDF 阅读器（常见为字体/渲染差异导致）

### 10.5 生成/导出文件失败（保存失败、写入失败）

优先检查：

- 文件是否已经被打开：Excel/WPS 打开着的文件通常无法被覆盖写入。请先关闭文件再重新导出。
- 保存路径是否有权限：尽量保存到桌面/文档等有写权限的目录；不要保存到只读U盘、系统受限目录或被网盘软件占用的同步临时目录。
- 文件名是否包含特殊字符：尽量使用中文、数字、下划线等常见字符，避免过长路径。

### 10.6 软件界面显示异常（按钮挤压、文字显示不全、布局错乱）

这类问题多数与 Windows “显示缩放”相关，建议按以下步骤处理：

1. 回到电脑桌面，右键 → “显示设置”
2. 将“缩放”调整为 100% 或 125%
3. 重新打开软件

### 10.7 监考编排无法生成（双监考特别常见）

可能原因与建议：

- 双监考下开启了“男女搭配/本外校搭配”，但教师信息里缺少“性别/是否本校”字段或数据不完整：补齐后重新导入教师信息。
- 约束过严导致无解：尝试取消部分约束、增加教师数量、提高最大监考段数、减少不监考科目限制后再生成。
- 预设监考考场过多/过死：如果很多老师被固定到某考场，系统可用空间变小，容易无解；适当减少预设或只对关键老师设置预设。

### 10.8 导入后名字对不上/提示找不到教师

优先检查：

- Excel 里是否有前后空格、全角/半角差异（例如“张三 ”与“张三”）
- 是否存在重名教师：建议用“姓名+编号/备注”做区分，或确保模板中姓名唯一
- 是否把教师名单分批导入导致缺人：建议一次性导入完整教师表

### 10.9 运行卡顿或无响应

常见触发点：

- 教师人数、考场数、科目数较大（尤其双监考 + 多约束），计算会更久：耐心等待进度条/日志提示；必要时先减少约束、先生成初稿再微调。
- 同时打开了很多大 Excel 文件：关闭无关 Excel/WPS 后再操作。
