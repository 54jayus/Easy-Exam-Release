# 智能考务系统

一个基于Python和PyQt5开发的图形化智能考务系统，可根据预设规则自动安排考试监考人员。

## 功能特点

1. 支持导入教师信息Excel表格
2. 提供单教师和双教师两种监考模式
3. 支持男女搭配和本外校搭配约束条件
4. 遵循平均工作量和教师不移动优化原则
5. 可视化界面操作，支持安排结果展示和导出
6. 支持手动调整监考安排（计划中）

## 环境要求

- Python 3.7 或更高版本
- PyQt5
- pandas
- openpyxl

## 安装步骤

1. 克隆或下载本项目代码

2. 安装依赖包：
   ```
   pip install -r requirements.txt
   ```

## 使用方法

1. 运行主程序：
   ```
   python main.py
   ```

2. 导入教师信息：
   - 准备Excel格式的教师信息表格
   - 表格应包含以下列：
     - 姓名：教师姓名
     - 性别：男/女（双教师模式下可选）
     - 是否本校：是/否（双教师模式下可选）
     - 最大监考段数：该教师最多可监考的场次数
     - 不监考科目：以逗号分隔的科目编号列表，如"1,3,5"

3. 设置考试参数：
   - 设置考试科目数和考场数
   - 选择监考模式（单教师或双教师）
   - 如需要，设置搭配约束条件

4. 生成监考安排：
   - 点击"安排监考"按钮
   - 系统将自动生成符合约束条件的监考安排

5. 查看和导出结果：
   - 在结果标签页中查看监考总览表、监考统计和分科目监考表
   - 可将结果导出为Excel文件
