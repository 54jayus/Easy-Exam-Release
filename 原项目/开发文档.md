# 智能考务系统开发文档

## 1. 项目概述

智能考务系统是一个用于自动化安排考试监考人员的工具，旨在简化学校考试期间的监考人员分配工作，确保监考安排符合各种约束条件和优化原则。

### 1.1 系统目标

开发一个基于Python的图形界面应用程序，能够根据预设规则和约束条件自动安排教师监考，并提供手动调整功能。

### 1.2 核心功能

1. 导入监考人员信息
2. 设置监考模式和约束条件
3. 自动安排监考
4. 展示和导出监考结果
5. 手动调整监考安排
6. 导入已有监考安排并补全未完成部分

## 2. 功能需求分析

### 2.1 监考人员信息管理

系统需要支持导入包含以下信息的表格：
- 姓名：教师姓名
- 性别：男/女（双教师模式下可选）
- 是否本校：是/否（双教师模式下可选）
- 最大监考段数：该教师最多可监考的场次数
- 不监考科目：以逗号分隔的科目编号列表，如"1,3,5"

### 2.2 监考模式

系统支持两种监考模式：

#### 单教师监考模式
- 每个考场只需要一个监考教师
- 对性别和是否本校没有特殊要求

#### 双教师监考模式
- 每个考场需要两个监考教师
- 支持以下搭配选项：
  - 男女搭配：两个监考教师必须为一男一女
  - 本外校搭配：两个监考教师必须为一本校一外校
  - 如果两个选项都启用，则需要同时满足两个条件

### 2.3 监考安排原则

系统在安排监考时需要遵循以下原则：

1. 必须满足的约束：
   - 不监考科目约束：教师不能被安排监考其不监考的科目
   - 男女搭配约束（双教师模式下可选）
   - 本外校搭配约束（双教师模式下可选）
   - 最大监考段数约束：教师监考次数不能超过其最大监考段数
   - **同一科目不重复监考约束：同一教师不能在同一科目中监考多个考场**

2. 优化原则：
   - 平均工作量原则：每个教师安排的监考次数尽量平均
   - 教师不移动原则：如果教师需要连续监考，尽量安排在同一考场

### 2.4 输入参数

用户需要输入以下参数：
- 考试科目数
- 考试场室数

### 2.5 输出结果

系统需要生成并展示以下信息表格：
1. 监考总览表：显示所有科目的监考安排
2. 监考统计表：显示每位教师的监考次数统计
3. 分科目监考表：按科目分类显示监考安排

所有表格应支持导出为Excel格式。

### 2.6 手动调整功能

系统应提供手动调整功能：
- 在监考总览表中点击两个监考教师的名字
- 点击按钮实现监考安排互换

### 2.7 导入监考安排功能

系统需要支持导入已有的监考安排，允许用户导入不完整的监考安排表，并在此基础上继续安排未完成的考场。

#### 功能要求：
1. 支持导入Excel格式的监考安排文件
2. 能够识别单教师和双教师监考模式
3. 正确处理空值情况：
   - 单教师模式：单元格为空表示该考场未安排监考教师
   - 双教师模式：监考员1或监考员2为空需要分别处理，特别是当启用本外校搭配约束时，需要确保监考员1为本校教师，监考员2为外校教师
4. 导入后更新界面显示，保持原有数据格式
5. 在现有安排基础上继续安排未完成的考场

### 2.8 监考安排补全功能

在导入不完整监考安排后，系统应支持补全功能，为未安排的考场继续分配监考教师。

#### 功能要求：
1. 检测未完成的考场安排
2. 根据当前监考模式和约束条件为未安排考场分配教师
3. 保持已安排考场的监考教师不变
4. 遵循所有监考安排原则和约束条件

## 3. 技术架构设计

### 3.1 技术栈

- 主窗口
- 参数设置界面
- 监考结果显示界面
- 手动调整界面

#### 3.2.5 数据导出模块
负责将监考安排结果导出为Excel文件

### 3.3 核心类设计

#### Teacher类
```python
class Teacher:
    def __init__(self, name, gender=None, is_internal=None, max_sessions=None, unavailable_subjects=None):
        self.name = name                    # 姓名
        self.gender = gender                # 性别 ('M'/'F')
        self.is_internal = is_internal      # 是否本校 (True/False)
        self.max_sessions = max_sessions    # 最大监考段数
        self.unavailable_subjects = unavailable_subjects or []  # 不监考科目列表
        self.assigned_sessions = []         # 已分配的监考场次
```

#### Exam类
```python
class Exam:
    def __init__(self, subject_id, rooms):
        self.subject_id = subject_id        # 科目编号
        self.rooms = rooms                  # 考场列表
        self.schedule = {}                  # 监考安排 {考场号: [监考教师列表]}
```

#### Schedule类
```python
class Schedule:
    def __init__(self, teachers, num_subjects, num_rooms, mode="single"):
        self.teachers = teachers            # 教师列表
        self.num_subjects = num_subjects    # 科目数
        self.num_rooms = num_rooms          # 考场数
        self.mode = mode                    # 监考模式 ("single"/"double")
        self.exams = []                     # 考试安排列表
        self.constraints = {}               # 约束条件
```

## 4. 算法设计

### 4.1 监考安排算法流程

1. 验证输入数据完整性
2. 根据监考模式和约束条件初始化安排环境
3. 按科目顺序进行监考安排：
   - 遍历每个考场
   - 根据约束条件筛选可用教师
   - 根据优化原则选择最合适的教师
4. 验证安排结果是否满足所有约束
5. 生成统计信息

### 4.2 约束满足检查

在安排每个考场监考时，需要检查：
1. 教师是否可以监考该科目
2. 教师是否还有监考名额
3. 是否满足性别搭配要求（双教师模式）
4. 是否满足本外校搭配要求（双教师模式）

### 4.3 优化策略

1. 平均工作量优化：
   - 优先选择监考次数较少的教师
   - 当多个教师监考次数相同时，随机选择或考虑其他因素

2. 教师不移动优化：
   - 在连续监考场次中，优先安排已在该考场监考的教师
