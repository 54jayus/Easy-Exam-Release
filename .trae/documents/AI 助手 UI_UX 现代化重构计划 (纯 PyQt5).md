# UI/UX 现代化设计方案 (纯 PyQt5 实现)

为满足您对“美观、现代、无第三方依赖”的需求，我将使用纯 PyQt5 配合 SVG 矢量绘图技术，为您重构一个精致的 AI 助手窗口。

## 1. 核心设计理念 (Design Principles)
*   **无边框沉浸式体验**: 移除系统原生标题栏，使用**自定义标题栏**，与窗口背景浑然一体，支持鼠标拖拽移动。
*   **呼吸感排版**: 增加留白 (White Space)，使用更柔和的背景色 (`#F7F9FC`) 与纯白卡片 (`#FFFFFF`) 形成层次。
*   **现代交互组件**:
    *   **胶囊按钮 (Pills)**: 用于快捷提问和附件展示，视觉轻量。
    *   **悬浮输入区**: 输入框不再是底部的死板横条，而是悬浮的卡片，发送按钮集成在内。
    *   **非对称气泡**: 模仿现代 IM 软件，消息气泡采用不对称圆角，更具对话感。

## 2. 视觉规范 (Visual Style)
*   **配色方案**:
    *   背景: `#F2F3F5` (冷灰)
    *   主色: `#3B82F6` (明亮蓝，用于发送/高亮)
    *   文字: `#1F2937` (深灰，避免纯黑的刺眼)
*   **图标系统**:
    *   内置一套 **SVG 矢量图标** (机器人、发送、附件、关闭、清空、浮窗等)，无需安装 `qtawesome` 或下载图片文件，保持代码纯净。
*   **动效与反馈**:
    *   按钮 Hover 时背景微亮或轻微上浮。
    *   输入框 Focus 时边框高亮。

## 3. 实现步骤 (Implementation Steps)
1.  **构建图标库**: 在代码中定义常用图标的 SVG 路径数据。
2.  **组件封装**:
    *   `ModernTitleBar`: 实现拖拽、最小化、关闭、标题显示。
    *   `ChatBubble`: 基于 QSS 的美化气泡，支持双击复制。
    *   `AttachmentChip`: 带删除按钮的附件小标签。
3.  **重写主窗口布局**:
    *   使用 `Qt.FramelessWindowHint` 移除原生边框。
    *   应用 `QGraphicsDropShadowEffect` 增加窗口立体感（如果系统环境支持）。
    *   重组布局：Top (Title) -> Center (Chat) -> Bottom (Input)。
4.  **交互逻辑迁移**: 确保原有的“深度思考”、“浮窗切换”、“发送线程”逻辑在新 UI 中正常工作。

## 4. 预期效果
*   界面将看起来像一个独立的现代 App，而不是传统的 Windows 98/XP 风格弹窗。
*   操作流畅，视觉愉悦，且**不增加任何 `pip` 依赖**。
