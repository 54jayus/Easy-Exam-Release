# 授权证书文件路径说明

本文说明智能考务系统在不同运行模式下，注册码证书文件 `license.cert` 的生成与存放路径，方便开发与部署时排查授权相关问题。

---

## 1. 只通过 Electron UI 使用软件时（推荐场景）

当只通过 Electron 桌面程序 UI 与后端交互时（包括开发模式和打包后的正式安装版本），后端 Python 进程由 Electron 主进程启动。

在这种情况下：

- 证书文件始终保存在 **Electron 可执行文件同级目录**；
- 路径形式为：

```text
<app_exe_dir>/license.cert
```

其中 `<app_exe_dir>` 为 Electron 返回的 `app.getPath('exe')` 所在目录。

### 1.1 开发模式（未打包）

在开发模式下（例如运行 `npm run dev` / `npm run electron:dev`）：

- `app.getPath('exe')` 一般指向项目内 `node_modules` 里的 Electron 可执行文件，例如：

```text
…\apps\desktop\node_modules\electron\dist\electron.exe
```

- 因此注册码证书文件的实际路径通常为：

```text
…\apps\desktop\node_modules\electron\dist\license.cert
```

可以直接在上述 `dist` 目录下查找并查看 `license.cert`。

### 1.2 打包后的安装版本

应用打包并安装后，例如安装到：

```text
C:\Program Files\ExamFlow\ExamFlow.exe
```

此时证书文件路径为：

```text
C:\Program Files\ExamFlow\license.cert
```

不论是第一次激活还是后续重新激活，都会对这个 `license.cert` 文件进行读写。

## 2. 证书路径的计算逻辑（后端实现原理）

后端证书路径由 `backend/licensing/cert_store.py` 决定，核心逻辑如下：

```python
def get_app_base_dir() -> Path:
    env_dir = os.getenv("EXAMFLOW_APP_DIR") or os.getenv("EXAMDESK_APP_DIR") or ""
    if env_dir.strip():
        return Path(env_dir).resolve()
    if getattr(sys, "frozen", False):
        return Path(sys.executable).resolve().parent
    return Path(__file__).resolve().parents[2]

def get_default_cert_path() -> Path:
    env_dir = os.getenv("EXAMFLOW_CERT_DIR") or os.getenv("EXAMDESK_CERT_DIR") or ""
    if env_dir.strip():
        return Path(env_dir).resolve() / "license.cert"
    return get_app_base_dir() / "license.cert"
```

规则总结：

- 如果设置了环境变量 `EXAMDESK_CERT_DIR`：  
  证书路径为 `EXAMDESK_CERT_DIR/license.cert`。
- 否则：
  - 若是打包后的 exe（`sys.frozen == True`）：
    - 证书路径在 exe 同级目录；
  - 若是普通 Python 运行（开发脚本、命令行直接运行）：
    - 证书路径在 `backend` 目录。

在 Electron 场景下，前端在启动 Python 后端时会显式设置：

```ts
env.EXAMDESK_APP_DIR = exeDir
env.EXAMDESK_CERT_DIR = exeDir
```

而 `exeDir` 来自主进程：

```ts
ipcMain.handle('app_exe_dir', () => {
  return path.dirname(app.getPath('exe'))
})
```

因此，对通过 Electron UI 启动的后端而言，可以简单记住：

> 证书文件 `license.cert` 永远与 Electron 可执行文件位于同一目录。

## 3. 直接运行 Python 后端时的行为（仅调试参考）

如果不通过 Electron，而是在命令行直接运行 Python 后端，例如：

```bash
D:/ANACONDA/envs/exam_scheduler/python.exe -m backend.rpc_server
```

且没有设置 `EXAMDESK_CERT_DIR` 环境变量，则：

- `get_app_base_dir()` 会回退到：

```python
Path(__file__).resolve().parents[2]
```

对于 `backend/licensing/cert_store.py` 来说，`parents[2]` 即项目中的 `backend` 目录；

- 因此此模式下，默认证书路径为：

```text
<项目根>/backend/license.cert
```

该路径与 Electron 模式下的 `license.cert` 相互独立，便于分别调试。
