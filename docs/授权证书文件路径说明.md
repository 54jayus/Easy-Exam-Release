# 授权证书文件路径说明

本文说明当前仓库中 `license.cert` 的保存与读取规则，方便在开发、打包和部署时排查授权问题。

## 1. 结论先看

在通过 Electron 桌面应用正常启动时，`license.cert` 默认保存在：

```text
<userData>/license.cert
```

也就是说：

- 开发态通常在 Electron 的 `userData` 目录
- 打包后通常在当前登录用户的数据目录中
- 覆盖安装或更换安装目录时，授权通常仍可保留

如果不通过 Electron，而是直接运行 Python 后端，默认会退回到仓库根目录：

```text
<repo_root>/license.cert
```

## 2. 当前代码中的路径计算逻辑

证书路径由 `backend/licensing/cert_store.py` 决定，核心逻辑如下：

```python
def get_app_base_dir() -> Path:
    env_dir = os.getenv("EXAMFLOW_APP_DIR") or os.getenv("EXAMDESK_APP_DIR") or ""
    if env_dir.strip():
        return Path(env_dir).resolve()
    if getattr(sys, "frozen", False):
        return Path(sys.executable).resolve().parent
    return Path(__file__).resolve().parents[2]

def get_default_cert_path() -> Path:
    env_dir = os.getenv("EXAMFLOW_CERT_DIR") or os.getenv("EXAMDESK_CERT_DIR") or ""
    if env_dir.strip():
        return Path(env_dir).resolve() / "license.cert"
    data_dir = os.getenv("EXAMFLOW_DATA_DIR") or os.getenv("EXAMDESK_DATA_DIR") or ""
    if data_dir.strip():
        return Path(data_dir).resolve() / "license.cert"
    return get_app_base_dir() / "license.cert"
```

根据这段代码，默认保存路径优先级为：

1. `EXAMFLOW_CERT_DIR` 或 `EXAMDESK_CERT_DIR`
2. `EXAMFLOW_DATA_DIR` 或 `EXAMDESK_DATA_DIR`
3. `EXAMFLOW_APP_DIR` 或 `EXAMDESK_APP_DIR`
4. 打包后 Python 可执行文件所在目录
5. 仓库根目录

## 3. Electron 模式下为什么现在会落到用户数据目录

桌面应用启动 Python 后端时，`frontend/src/lib/pythonBackend.ts` 会向主进程请求当前应用目录，随后把这些变量传给后端：

- `EXAMFLOW_APP_DIR`
- `EXAMDESK_APP_DIR`

同时，Electron 主进程在启动 Python 进程时会自动补充：

- `EXAMFLOW_DATA_DIR`
- `EXAMDESK_DATA_DIR`

它们的值来自 Electron 的：

```ts
app.getPath('userData')
```

因此在 Electron 模式下，后端会优先把证书保存到用户数据目录，而不是安装目录。

## 4. 开发态路径

开发态运行 `npm.cmd run dev` 时，`app.getPath('exe')` 通常指向 Electron 自带的可执行文件，例如：

```text
<repo_root>/frontend/node_modules/electron/dist/electron.exe
```

因此证书默认通常位于：

```text
%APPDATA%/<应用标识>/license.cert
```

如果你在开发时已经激活过一次软件，优先检查 Electron 对应的 `userData` 目录，而不是 `electron.exe` 所在目录。

## 5. 打包后路径

打包安装后，主程序通常位于：

```text
C:\Program Files\Easy Exam\Easy Exam.exe
```

但证书默认位于当前用户的数据目录中，常见形式类似：

```text
%APPDATA%\Easy Exam\license.cert
```

因此覆盖安装、修改安装路径或升级版本时，授权信息通常不会因为安装目录变化而丢失。

## 6. 直接运行 Python 时的路径

如果不是通过 Electron 启动，而是直接在命令行中运行后端，例如：

```powershell
$env:PYTHONPATH='.'
python -m backend
```

且没有额外设置 `EXAMFLOW_CERT_DIR` / `EXAMDESK_CERT_DIR`，默认会退回到：

```text
<repo_root>/license.cert
```

这里的 `<repo_root>` 指仓库根目录，而不是 `backend/` 目录。

## 7. 读取证书时的补充回退逻辑

当前默认路径中没有证书时，程序会继续尝试读取旧位置，用于兼容历史版本。常见读取顺序为：

1. 默认证书路径
2. 安装目录 / 主程序目录下的旧 `license.cert`
3. 仓库根目录下的 `license.cert`
4. 当前工作目录下的 `license.cert`

如果从旧安装目录读取到了有效证书，程序会优先迁移并保存到新的默认位置。

## 8. 排查建议

如果授权异常，建议按顺序检查：

1. 当前是否通过 Electron 启动
2. Electron 主进程拿到的 `app.getPath('userData')` 是什么
3. `license.cert` 是否存在于该目录
4. 旧安装目录中是否残留历史证书
5. 仓库根目录或当前工作目录里是否残留旧证书
