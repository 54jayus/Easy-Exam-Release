Easy Exam 打包命令速查

推荐方式：

1. 在仓库根目录执行
   python package.py

package.py 当前会执行两步：

1. 使用 frontend/engine.spec 构建 Python sidecar
2. 在 frontend/ 目录执行 npm.cmd run electron:build

可选环境变量：

- EXAM_PYTHON_MODE
- EXAM_CONDA_ENV
- EXAM_CONDA_EXE
- EXAM_PYTHON_EXE

如果只想手动执行第二步：

1. 进入 frontend 目录
2. 执行 npm.cmd run electron:build

如果 package.py 报找不到 Python：

1. 先确认 .env.runtime.local 已按本机环境填写
2. 如使用 Conda，确认 EXAM_CONDA_ENV 和 EXAM_CONDA_EXE 可用
3. 或显式设置 EXAM_PYTHON_EXE
